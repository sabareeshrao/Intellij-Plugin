# IntelliJ Lesson Plugin

Native IntelliJ IDEA execution engine for the AeroTopo lesson curriculum.

This repository contains the IntelliJ Platform plugin runtime only. Lesson content remains in `sabareeshrao/Java-Practice-Project`; the browser simulator remains in `sabareeshrao/Experiment-VS-Code`.

The first milestone is intentionally narrow: load the existing course, show it in a native IntelliJ Tool Window, persist learner position, and support real `openFile` navigation with Previous / Replay / Next state handling.
